## 🧠 Key Lessons

- Understand the problem before writing code.
- Keep loop variables updated to avoid infinite loops.
- Use `%` to extract digits and test divisibility.
- Preserve original collections when an operation modifies them.
- Use appropriate data structures for the problem.
- Trace code manually with a dry run before submitting.
- Learn why a solution works instead of memorizing it.
